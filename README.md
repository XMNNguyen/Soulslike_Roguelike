# What is this?
This is a prototype I am making for a soulslike roguelike 3d game using the Godot Engine. The goal of this project is to learn more about enemy design and learning how to rig and animate 3d objects using Blender and Godot.

# What will the game have?
The game will have combat that will be similar to a hybrid of the fast paced combat in Zelda BOTW/TOTK and the more deliberate combat in Sekiro and the Souls trilogy from Fromsoftware. The player will enter different areas with a linear choice of rooms as they explore. To get through each room, the player will have to kill the boss monster at the end of each room. This will be updated as the game progresses.
